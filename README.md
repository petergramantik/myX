# myX

Mobilní webová aplikace (PWA) – logbook ponorů s X-CCR a počítačem Shearwater Petrel 2.

- Import exportu databáze ze Shearwater Cloud (Profile → Options → Export Database)
- Lokality (párování se Stranami potápěčskými, poloha, počasí) a parťáci
- Grafy ponoru: profil, pO₂ a články, CO₂, dekomprese, tlaky lahví, baterie, tkáně
- Upozornění na scrubber, baterii a vysoké CO₂
- Synchronizace přes Cloudflare Worker (`proxy/worker.js`)

Web: https://petergramantik.github.io/myx/
